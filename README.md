# 강호촌 영주기 (江湖村領主記)

무협지 속 이름 없는 작은 마을의 영주가 되어, 마을을 강호에 이름 높은 현성(縣城)으로 키워 내는 2D 마을 경영 게임.

정파와 사파, 녹림의 산적, 마교, 관부와 상단이 얽힌 세상에서 마을 사람들은 스스로 일하고 먹고 잠든다.
영주는 무엇을 지을지, 누구와 손잡을지, 습격에 어떻게 맞설지를 정한다.

## 실행

설치나 빌드가 필요 없다. `index.html`을 브라우저로 열면 바로 시작된다.

```bash
# 또는 간단한 로컬 서버로
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

진행 상황은 매일 아침 브라우저(localStorage)에 자동 저장되고, 상단의 **저장** 버튼으로 직접 저장할 수도 있다.

## 게임의 흐름

- **낮과 밤**: 하루는 1배속 기준 2분. 묘시에 일어나 일터로 가고, 유시가 지나면 객잔·시장·정자로 마실을 나가고, 해시에는 집으로 돌아가 불을 밝힌다. 밤에는 무사 절반이 횃불을 들고 야경을 돈다.
- **사계절**: 봄·여름·가을·겨울이 각 10일. 가을에 수확이 가장 많고 겨울에는 논밭이 거의 쉬므로 미리 곳간을 채워야 한다. 계절마다 땅과 나무, 지붕의 눈, 날리는 꽃잎·낙엽·눈이 바뀐다.
- **성장**: 빈 집, 넉넉한 식량, 민심 42 이상이면 새 식구가 관도를 따라 찾아온다. 인구 15·35·70·120에서 마을→읍→진→현성으로 승격하며 새 건물이 열린다.
- **승리**: 현성(인구 120)과 명성 400을 이루면 "천하제일촌". 이후에도 계속 다스릴 수 있다.

## 강한 사건들

| 종류 | 내용 |
| --- | --- |
| 습격 | 세력과의 관계가 나빠지면 위협이 쌓이다가 척후의 경보와 함께 무리가 쳐들어온다. 무사·객경·망루·원군이 실시간으로 싸우고, 적은 목책을 부수고 건물을 약탈하고 불태운다. |
| 점령 | 혈월교·철혈방·관부는 영주관을 노린다. 영주관이 무너지면 마을이 점령되어 매일 수탈당한다. 몸값을 치르거나, 무사를 길러 봉기하거나, 우호 세력의 도움을 받아 되찾는다. |
| 포섭 | 청운검문·철혈방·혈월교가 산하로 들어오라고 제안한다. 주군을 두면 공물을 바치는 대신 습격 때 원군이 오고 고유한 혜택이 생기지만, 그 원수들과는 척을 진다. 주군을 바꾸면 배신이 된다. |
| 그 밖 | 흑풍채의 통행세, 철혈방의 보호비, 객잔의 떠돌이 고수, 석함 속 비급, 정사대전, 무림대회, 역병, 가뭄, 풍년, 호환, 첩자, 뒷산 동굴, 혼례, 명절, 징병령, 현령 시찰 등 30여 가지. |

## 세력

| 세력 | 성향 | 산하가 되면 |
| --- | --- | --- |
| 청운검문 | 정파 | 무사 수련 +50%, 원군 |
| 철혈방 | 사파 | 도박장 수입, 원군, 관부의 눈총 |
| 흑풍채 | 녹림 | (산하 불가) 늘 재물을 노린다 |
| 혈월교 | 마교 | 무사 공격력 +30%, 은자, 민심 -10, 정파·관부의 적의 |
| 관부 | 관청 | 세금 +15%, 산적 위협 절반 |
| 금룡상회 | 상단 | 시장·객잔·표국 수입 +30% |

## 조작

| 입력 | 동작 |
| --- | --- |
| 좌클릭 | 선택 · 건설 |
| 끌기 / 우클릭 끌기 | 지도 이동 |
| 휠 / 두 손가락 | 확대·축소 |
| W A S D · 방향키 | 지도 이동 |
| Space | 일시정지 |
| 1 2 3 | 속도 |
| Esc · 우클릭 | 건설 취소 · 선택 해제 |

길·목책·석벽은 끌어서 한 번에 깔 수 있다. 건물을 누르면 일꾼 수 조절, 가동 중지, 수리, 기와집 증축, 철거를 할 수 있다.

## 구조

외부 라이브러리와 이미지 없이 HTML5 Canvas와 순수 JavaScript로 만들었다. 건물·나무·사람은 모두 코드로 그린다.

```
index.html        화면 뼈대
css/style.css     옻칠 나무 패널과 한지 두루마리 스타일
js/util.js        상수, 난수, 노이즈, 저장소, 한국어 조사 처리
js/data.js        시간·등급·경지·건물·세력·이름 데이터
js/world.js       지형 생성, 점유 지도, A* 길찾기
js/sprites.js     건물·나무·사람 그림
js/render.js      지형 캐시, 깊이 정렬, 낮밤 조명, 날씨, 미니맵
js/units.js       마을 사람의 하루, 이동, 전투 AI
js/sim.js         경제, 건설, 일자리 배치, 민심, 습격, 점령, 저장
js/events.js      사건 정의와 습격 경보
js/ui.js          상단 띠, 건설 메뉴, 정보 패널, 세력·현황 창, 사건 창
js/main.js        입력, 게임 루프, 시작 화면
```

새 사건은 `js/events.js`의 `EV`에, 새 건물은 `js/data.js`의 `BDEF`와 `js/sprites.js`의 `DRAW`에 추가하면 된다.
