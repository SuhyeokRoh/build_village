# 강호(江湖) 확장 설계 — 천하도, 일곱 계열, 갈림길

이 문서는 세력 확장의 설계이자 모듈 사이의 약속이다. `docs/architecture.md`의 규칙(투영, 저장, 훅, Bus, 한자 풀이)은 그대로 지키고, 여기서 정한 이름과 모양은 바꾸지 않는다. 바꿔야 하면 이 문서를 먼저 고친다.

## 0. 목표 (영주의 요청)

1. 세력이 너무 적다 → **일곱 계열**(정파·마교·무림세가·흑도·사파·새외무림·관)과 중립 상단, 계열마다 서너 세력, 모두 스물여섯.
2. **시작 위치**를 고르면 그 둘레의 세력이 이웃이 된다. 고을마다 땅 생김(숲·물·산·기름진 들·추위)도 다르다.
3. 내 마을 지도뿐 아니라 **천하도(天下圖)** 로 천하의 세력 판도와 전쟁, 계열별 세력 양상을 본다.
4. 할 일이 너무 적다 → 외부 세력이 일으키는 **다채로운 사건**, **의뢰(파견)**, **외교**(사신·교역·동맹·현상금·첩자), **전쟁 지원**.
5. 길이 하나뿐이다 → 제4장 **갈림길**에서 어느 계열과 손잡느냐(또는 홀로 서느냐)에 따라 제5·6장과 결말이 갈린다. **여덟 갈래**.

## 1. 계열 (data.js `CAMPS`, `CAMP_ORDER`, `CAMP_ATT`)

```js
CAMPS[key] = {
  name: '정파', hanja: '正派', seal: '正', color: '#4f7fb8',
  desc: '…',                      // 한 줄 성격
  perk: { train: 1.5, happy: 3, aid: true },   // 산하일 때(동맹은 절반, §5)
  perkText: '무사 수련 +50%, 민심 +3, 습격 때 원군',
  route: 'jeong',                 // 이 계열과 손잡으면 걷는 갈래 (§8)
}
CAMP_ORDER = ['jeong', 'sega', 'gwan', 'sang', 'saeoe', 'sa', 'heuk', 'ma']
CAMP_ATT[a][b]  // -100..100, 계열끼리의 기본 감정. 대칭. 자기 자신은 50.
```

| key | 이름 | 표 | 산하 혜택 `perk` (동맹이면 수치 효과의 절반, `aid`는 그대로) |
| --- | --- | --- | --- |
| jeong | 정파(正派) | 正 | `train 1.5`, `happy 3`, `aid` |
| ma | 마교(魔敎) | 魔 | `atk 1.3`, `dailySilver 0.4`(인구당), `happy -10`, `aid` |
| sega | 무림세가(武林世家) | 家 | `heroEvery 12`(일마다 가문 무인 하나), `fame 0.3`(매일), `aid` |
| heuk | 흑도(黑道) | 黑 | `dailySilver 0.3`(밀수), `bandit 0.5`(흑도 습격 위협 절반), `gwanRel -1`(매일) |
| sa | 사파(邪派) | 邪 | `dailySilver 0.35`(도박장), `gwanRel -1`, `aid` |
| saeoe | 새외무림(塞外武林) | 外 | `hp 1.2`(무사 체력), `trade 1.15`, `gwanRel -0.5`, `aid` |
| gwan | 관(官) | 官 | `tax 1.15`, `bandit 0.5`, `aid` |
| sang | 상단(商團) | 商 | `trade 1.3` (군사가 없어 `aid` 없음) |

`CAMP_ATT` 기본값 (적지 않은 칸은 0):

- jeong–ma −90, jeong–sa −50, jeong–heuk −60, jeong–sega +30, jeong–gwan +10, jeong–saeoe −20
- ma–sega −60, ma–gwan −70, ma–sa −10, ma–saeoe −10
- sega–sa −30, sega–heuk −40, sega–gwan +20, sega–saeoe −10
- heuk–gwan −70, heuk–sa +20, heuk–sang −20
- sa–gwan −40
- saeoe–gwan −40
- gwan–sang +10

**관계 번짐**: 영주가 세력 X와 가까워지거나(예물·사신·의뢰·산하·동맹) 멀어지면, 다른 세력 Y의 관계가 `Δ × CAMP_ATT[camp(X)][camp(Y)] / 100 × 0.5` 만큼 따라 움직인다(같은 세력 제외, 반올림 없이). 지금의 `rivals` 규칙을 이것으로 바꾼다. `changeRel(k, d)`는 그대로 두고 번짐은 `JH.relSpread(k, d)`로 따로 부른다(예물·사신·산하·동맹·의뢰 결과에서만, 습격 결과의 관계 변화에는 번지지 않는다).

## 2. 세력 (data.js `FACTIONS`, `FACTION_ORDER`)

`FACTIONS`는 지금처럼 id로 찾는 사전이다. 기존 여섯 id(`cheongun cheolhyeol heukpung hyeolwol gwanbu geumryong`)는 **그대로 남긴다**(옛 저장, 이야기, 사건이 쓴다). 모양:

```js
FACTIONS[id] = {
  name, hanja,            // 문장 한 글자 (스물여섯 모두 다르게)
  camp,                   // CAMPS 키
  type,                   // 보이는 글: `${CAMPS[camp].name}(${CAMPS[camp].hanja})` 와 같게 둔다 (옛 코드 호환)
  color, dark, desc,
  unit, leader,           // 군사가 있는 세력만 (지금 모양 그대로: unit.name/hp/atk/weapon/hat/cloth/cloth2)
  military, baseSize, growth, goals,   // 지금 뜻 그대로
  startRel,               // 이웃일 때의 첫 관계
  home,                   // REGIONS 키 (본산이 있는 곳). 'local' 이면 고을마다 곁에 생긴다
  power,                  // 처음 힘 (30..120)
  noLord,                 // 산하·동맹 불가 (산적 떼)
  temper: { greed, honor, aggro },     // 0..1, 사건·의뢰·전쟁 성향
}
FACTION_ORDER  // 스물여섯 id 전부 (계열 순서대로)
```

세력 목록 (이름은 모두 이 게임만의 것이다):

| 계열 | id · 이름 · 문장 · 본산 |
| --- | --- |
| 정파 | `cheongun` 청운검문 靑 섬서 · `baekhak` 백학문 鶴 호북 · `geumgang` 금강사 剛 하남 · `taeheo` 태허관 虛 사천 |
| 마교 | `hyeolwol` 혈월교 血 서역 · `heungnyeon` 흑련교 蓮 운귀 · `cheongwi` 천귀문 鬼 호남 |
| 무림세가 | `baengni` 백리세가 百 하북 · `jegal` 제갈세가 葛 호북 · `sanggwan` 상관세가 上 강남 |
| 흑도 | `heukpung` 흑풍채 黑 local · `heuksu` 흑수채 水 강남 · `gwiyeong` 귀영문 影 하남 · `hyeolyeong` 혈영루 樓 산동 |
| 사파 | `cheolhyeol` 철혈방 鐵 강남 · `mandok` 만독곡 毒 운귀 · `chilsal` 칠살문 殺 산서 |
| 새외 | `bingseol` 빙설궁 氷 북해 · `geumryun` 금륜사 輪 서장 · `yasu` 야수궁 獸 남만 · `haerang` 해랑도 狼 동해 |
| 관 | `gwanbu` 관부(현청) 官 local · `geumui` 금의위 錦 하북 · `jinbuk` 진북군 北 요동 |
| 상단 | `geumryong` 금룡상회 金 강남 · `malli` 만리표국 鏢 하남 |

- `local` 세력(흑풍채, 관부)은 어느 고을에서 시작하든 그 곁에 본산이 생기고 늘 이웃이다. 흑풍채는 튜토리얼의 적이다.
- 이웃이 아닌 세력도 `S.factions`에 다 있다(관계는 0에서 시작). 다만 습격·포섭·이웃 사건은 이웃만 일으킨다(§4).
- 군사가 있는 새 세력은 모두 `unit`과 `leader`를 갖는다. 생김(무기·모자·옷 색)은 계열 분위기에 맞춘다: 불문은 민머리(`hat: 'bald'`가 없으면 'band'), 새외는 털모자 등. `units.js`/`sprites.js`가 모르는 값은 쓰지 않는다(알려진 값만: weapon `sword blade spear axe staff fan bow`, hat `band hood mask helmet hat` — 실제 sprites.js의 목록을 확인해 그 안에서 고른다).

## 3. 천하 지리 (data.js `REGIONS`, `SITES`)

천하도 좌표계: 가로 1000 × 세로 700, 동쪽이 오른쪽, 북쪽이 위.

```js
REGIONS[key] = { name: '섬서', hanja: '陝西', x, y, outer: false, desc }   // x,y = 지역 중심
SITES[key] = {
  name: '운무곡', hanja: '雲霧谷', region: 'shaanxi', x, y,
  desc: '…',
  biome: { forest: 0..1, water: 0..1, hills: 0..1, fertile: 0..1, cold: 0..1 },
}
```

- 지역 열여섯: 중원 열둘(하북 河北, 산동 山東, 산서 山西, 섬서 陝西, 하남 河南, 호북 湖北, 호남 湖南, 강남 江南, 사천 四川, 운귀 雲貴, 복건 福建, 광동 廣東) + 새외 넷 이상(북해 北海, 서역 西域, 서장 西藏, 남만 南蠻, 동해 東海, 요동 遼東 — `outer: true`). 키는 영문 소문자(`hebei shandong shanxi shaanxi henan hubei hunan jiangnan sichuan yungui fujian guangdong beihai xiyu xizang nanman donghai liaodong`).
- 지역 경계는 중심점들의 보로노이로 그린다(천하도 격자 칸마다 가장 가까운 중심). 새외 지역은 가장자리에 둔다. 황하(黃河)·장강(長江) 두 강줄기를 고정된 곡선으로 그린다.
- 고을(시작 자리) 열 곳 이상. 서로 다른 지역에, 이웃 세력의 짜임과 땅 생김이 고르게 다르게. 예: 섬서 산골(산 많고 돌 많음), 하남 들녘(기름짐), 강남 수향(물 많음), 사천 분지(숲), 운귀 변경(숲·위험), 하북 관도(추움·평지), 산동 해안(물), 요동 국경(아주 추움), 호북 강가(물·숲), 호남 숲, 서역 오아시스(메마름·위험).

## 4. 천하 상태 (js/jianghu.js, `S.jh`)

`js/jianghu.js`가 새 모듈 `JH`다. `S.jh`는 순수 JSON:

```js
S.jh = {
  v: 1,
  site: 'yunmu',                 // SITES 키
  seats: { [id]: { x, y } },     // 본산 자리 (천하도 좌표). local 세력은 고을 곁 30~60 거리
  power: { [id]: number },       // 힘. 0 이면 멸문(활동하지 않음). 상한 200
  near: [id, ...],               // 이웃 세력 (게임 시작 때 정하고, 멸문하면 빠진다)
  wars: [ { id, a: [ids], b: [ids], name, since, score, help: { a: 0, b: 0 }, front: { x, y } } ],
  news: [ { day, text, kind, f: [ids] } ],     // 최근 40개 (새것이 앞)
  quests: [ Quest ],             // §6
  allies: [ids],                 // 동맹 (최대 2). 산하(주군)는 지금처럼 S.vassal
  route: null,                   // 갈래 (§8). 이야기 모듈이 정하고 JH 는 읽기만 한다
  spies: { [id]: untilDay },     // 첩자가 들어가 있는 세력
  trade: { [id]: untilDay },     // 교역 협정
  nextWarCheck: day, nextQuestAt: time,
}
```

**이웃 정하기**: 고을 자리에서 각 본산까지 거리 d, 영향 `power / (1 + (d/120)^2)`. local 둘 + 영향이 큰 순서로 이웃 넷~다섯을 뽑되, 적어도 서로 다른 계열 셋이 들어가게 한다. 거리 250 밖은 이웃이 될 수 없다.

**영역**: 천하도 격자(가로 100 × 세로 70 칸)마다 영향이 가장 큰 세력이 그 칸의 주인. 영향이 일정값 아래면 빈 땅. 렌더링 전용이라 저장하지 않고 `JH.territory()`가 필요할 때 셈해 캐시한다(힘이 바뀌면 무효화).

**하루 흐름 `JH.daily()`** (sim.js `dailyTick` 끝에서 부른다):
- 힘: `power += growth × (0.5..1.5)`, 전쟁 중이면 점수에 따라 오르내림. 상한 200, 0 이하면 멸문(뉴스, 이웃에서 빠짐, 그 무리의 남은 이들이 사건으로 찾아올 수 있다).
- 전쟁: 사흘마다 한 번 새 전쟁을 따진다. 동시에 최대 셋. 후보는 `CAMP_ATT`가 −40 아래인 두 세력(또는 계열 연합)이 거리 400 안. 이름은 판에 따라: 정마대전(正魔大戰), 정사대전(正邪大戰), 토벌전(관 대 흑도), 새외 침공, 세가 분쟁, 흑도 쟁패. 날마다 `score += (힘a+help.a − 힘b−help.b)/50 + 무작위`; |score| ≥ 10 이면 끝. 진 쪽 힘 −30%, 이긴 쪽 +15%. `help`는 영주의 지원(§7)이 쌓이고 하루에 절반씩 줄어든다.
- 소식: 전쟁 시작·끝, 멸문, 세력 급성장, 무림대회 등은 `JH.news()`로 남긴다. 이웃이 얽힌 큰 소식은 마을 기록(logMsg)과 알림에도 띄운다.
- 의뢰: 하루 0~2개가 새로 붙는다(§6). 기한이 지난 것은 사라진다.
- 동맹·교역·첩자 기한 처리, 동맹 혜택(§5).

**옛 저장**: `S.jh`가 없으면 `JH.migrate()`가 `S.seed`로 천하를 만들고 고을은 `'henan_field'`(하남 들녘)로 둔다. 옛 여섯 세력의 관계·위협·산하·점령은 그대로 두고, 나머지 세력은 관계 0으로 더한다.

## 5. 산하·동맹·혜택 (`JH.perk`)

- **산하**(지금의 vassal): 그대로. 조건 관계 40 이상, 이웃이어야 한다. 매일 공물.
- **동맹**(새로): 이웃이고 관계 60 이상, 명성 60 이상, 그 세력이 주군의 적대 계열(`CAMP_ATT` < −40)이 아니어야 한다. 공물 없음. 혜택은 수치의 절반(`aid`는 그대로). 동맹은 최대 둘. 동맹이 전쟁에 들면 지원을 청하는 사건이 오고, 외면하면 관계가 깎인다.
- 혜택은 코드 곳곳의 `S.vassal === 'cheongun'` 같은 분기를 모두 없애고 `JH.perk(name)`으로 읽는다:
  - `JH.perk('train')` → 곱 (기본 1), `atk`, `hp`, `tax`, `trade` 도 곱.
  - `JH.perk('happy')`, `fame`, `dailySilver`(인구당), `gwanRel` → 더하기 (기본 0).
  - `JH.perk('bandit')` → 흑도 계열 위협 증가 곱 (기본 1).
  - `JH.perk('aid')` → 원군을 보낼 수 있는 주군·동맹 id 목록.
- `happinessFactors`는 산하·동맹마다 줄을 따로 보인다: 예 `['정파의 비호(청운검문)', 3]`.

## 6. 의뢰와 파견 (Quest)

```js
Quest = {
  id, fid,                // 의뢰한 세력
  kind,                   // 'escort' 호위 · 'suppress' 토벌 · 'scout' 정탐 · 'retrieve' 탈환 · 'war' 원군 · 'assassin' 암살 · 'smuggle' 밀수 · 'herb' 약재
  title, text,            // 보이는 글 (한자에는 풀이)
  target,                 // 토벌·암살 대상 세력 id (없으면 null)
  need: { n, martial },   // 보낼 사람 수와 권하는 무공 합
  days,                   // 다녀오는 날 수
  reward: { silver, fame, rel, items? },
  risk,                   // 0..1, 다치거나 죽을 위험
  expires,                // 이 날이 지나면 사라진다 (dayOf 기준)
  state: 'open' | 'away' | 'done' | 'failed',
  party: [villagerId],    // 보낸 이들
  back,                   // 돌아오는 S.time
}
```

- 의뢰는 이웃이 대부분 내고, 먼 세력은 객잔·표국이 있을 때 가끔 낸다. 계열마다 어울리는 종류: 정파·관 → 토벌·정탐·원군, 세가 → 탈환·호위·원군, 흑도·사파 → 밀수·암살·정탐, 마교 → 암살·원군, 새외 → 약재·호위, 상단 → 호위·약재.
- `JH.dispatch(qid, ids)`: 무사(`role==='guard'` 또는 객경)를 보낸다. 보낸 이에게 `v.away = { q: qid, until }`을 달고, 그들은 가장 가까운 길목으로 걸어 나간 뒤 지도에서 사라진다(`units.js`가 처리: 길목에 닿으면 `v.inside = 'away'`처럼 숨긴다). 일자리는 비운다.
- 돌아올 때(`until` 지남) 성공 판정: `p = clamp(0.35 + (무공합 − need.martial) × 0.08 + 0.1 × (n − need.n), 0.1, 0.95)`. 성공 → 보상, 관계 `+rel`(+번짐), 토벌·암살이면 대상 세력 힘 −8~−15와 관계 −15. 실패 → 보상 없음, 관계 −3. `risk`에 따라 다치거나(체력 1/3) 드물게 죽는다. 길목에서 다시 들어와 일터로 돌아간다. 결과는 마을 기록과 알림, 의뢰 기록(`S.jh.quests`의 done/failed, 최근 10개만 남긴다).
- 밀수·암살은 관과의 관계를 깎는다(`gwan` 계열 −4 번짐). 원군 의뢰는 해당 전쟁의 `help`에 무공합 × 2를 더한다.
- 파견 중인 사람은 `fighters()`, 일자리, 순찰, 습격 방어에서 빠진다. 인구에는 든다.

## 9. 사건 (events.js)

- 지금 사건은 남기되, 특정 세력에 묶인 것은 **계열 일반**으로 넓힌다: `cheongun_offer`/`hyeolwol_offer` → 이웃 중 한 세력을 골라 `offer`(포섭 제안), `gang_protection` → 이웃 흑도·사파 하나, 등. 대상 세력은 `init`에서 `JH.pickNear(camp)`로 고른다(없으면 사건을 버린다).
- 새 사건 서른 개 이상. 계열마다 셋 이상 + 전쟁 번짐 + 천하 소식. 예:
  - 정파: 무림맹 소집(무사 파견 청), 협객의 방문(객경), 정파의 감찰(마교와 가까우면 문책), 비무 초청.
  - 마교: 제물 요구, 마공 비급의 유혹, 마교 첩자 색출, 토벌을 피한 마교도의 은신 요청.
  - 세가: 혼담(혼인 동맹: 동맹 조건 완화 + 가문 무인 합류), 후계 다툼(편 들기), 세가의 비급 거래.
  - 흑도: 밀수 제안, 장물 거래, 수적 출몰, 살수 의뢰(경쟁 세력 사신을 노린다).
  - 사파: 도박장 개설 제안, 독 거래, 사파 회맹 초대.
  - 새외: 새외 상인(말·인삼), 새외 무인 방문, 국경 침입 소문, 포로 송환.
  - 관: 토벌령(관 편에 서기), 수배자 은닉 청, 관직 제의, 염세 단속.
  - 전쟁 번짐: 전쟁 난민, 군량 징발, 패잔병, 전장 줍기, 양쪽 사신이 동시에 찾아와 편을 들라 한다.
  - 천하 소식: 멸문한 세력의 생존자, 무림대회 개최(갈래와 상관없이 명성), 천하의 기운(전쟁 결과에 따른 교역 변화).
- 사건 `stamp`와 본문 한자에는 풀이가 있어야 한다(§6 of architecture). 새 한자는 `HANJA_GLOSS`에 더한다.
- 이웃이 아닌 세력의 사건은 객잔·표국이 있거나 그 세력이 전쟁 중일 때만, 낮은 빈도로.

## 11. 화면·흐름의 나머지

- **메뉴**: `#menubar`에 [천하도] 단추(`#btn-worldmap`, 文: 天). 갈래가 정해지면 [세력] 창 위에 갈래 표가 보인다.
- **새 게임**: 이름 → 천하도 고르기 모드 → 고른 고을로 `newGame(name, siteKey)` → 총관 소개(고을과 이웃 이야기) → 튜토리얼. 고르기를 닫으면 제목 화면으로.
- **세력 창**(ui.js `factionsHTML`): 위에 탭 [세력 · 의뢰 · 소식]. 세력 탭은 **이웃**을 먼저(지금 카드 + 새 단추: 사신, 교역, 동맹, 현상금, 첩자, 전쟁 지원), 먼 세력은 계열별로 접힌 목록(관계, 힘, 전쟁만; 사신·예물은 가능). 의뢰 탭: 열린 의뢰 카드(보낼 사람 수 고르기 → [보낸다]), 다녀오는 중(남은 날), 지난 결과. 소식 탭: `S.jh.news`.
- **마을 지도**: 고을의 `biome`이 `genWorld(seed, biome)`에 들어가 숲·물·바위·흙의 문턱을 바꾼다(지금 땅이 biome 기본값과 같아야 한다: 모두 0.5일 때 지금과 같은 결과). 길목 넷(서·동·북·남)에는 그 방향에 있는 이웃 세력 이름이 붙는다(`exit.toward = [ids]`). 습격은 그 세력 본산 방향의 길목으로 온다: `JH.exitFor(id)`.
- **도움말**·README: 계열, 천하도, 의뢰, 외교, 갈림길을 짧게.
